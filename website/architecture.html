System Architecture & Pipeline Dataflow

MDRAP is designed as a standalone, non-intrusive sidecar. It sits upstream of algorithmic pricing engines, validating market data before it reaches trading strategies.

Core Subsystems & Architectural Guarantees

Dual-Tier Execution

MDRAP supports two execution tiers: an ultra-fast compiled C hot path for high-throughput institutional feeds, and an identical pure-Python fallback guaranteeing 100% semantic parity across all platforms.

Zero External Brokers

No external brokers (Kafka, Redis, RabbitMQ) required. By relying on embedded SQLite WAL and shared memory, MDRAP eliminates network broker failure modes.

VirtualClock Determinism

Replay execution operates against historical exchange timestamps rather than wall-clock time, ensuring zero jitter and bit-for-bit reproducibility during post-mortem audits.
