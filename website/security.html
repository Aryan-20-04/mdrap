● ZERO-TRUST READ-ONLY ASSURANCE BOUNDARY

Zero Execution Risk by Design

MDRAP eliminates the primary risk vector of financial software: private trading keys. By design, MDRAP cannot place orders, modify positions, or access brokerage funds.

CORE DEFENSES

Institutional Infosec Guarantees

Zero Private Secrets

MDRAP connects strictly to public WebSocket feeds and multicast streams. It does not accept, store, or transmit API secrets, passphrases, or private signing keys.

Loopback Isolation

The internal REST and WebSocket APIs bind strictly to 127.0.0.1. The sidecar cannot be reached from external networks without explicit proxying.

Cryptographic Salt

API tokens and hash operations enforce a 32-byte cryptographic salt (MDRAP_API_KEY_SALT). The daemon refuses to start if default salts are detected.
