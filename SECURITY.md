# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.2.x   | :white_check_mark: |
| < 1.2   | :x:                |

## Reporting a Vulnerability

The MDRAP maintainers take security and data reliability seriously. If you discover a vulnerability or security-sensitive defect in MDRAP (including native C accelerator frame parsing or cryptographic audit verification):

1. **Do not open a public GitHub issue.**
2. Send an email with details, reproduction steps, and potential impact to security@mdrap.org (or contact the repository maintainers via GitHub private vulnerability reporting).
3. We will acknowledge receipt of your report within 48 hours and provide a timeline for triage and remediation.
4. Security advisories and patched releases will be published through GitHub Security Advisories.
