# MDRAP Contrib

`mdrap-contrib` contains the MDRAP command line and optional/peripheral modules.
Install it alongside `mdrap-core` to use `mdrap` CLI commands or modules such as
portfolio, strategy, terminal, and exchange protocol integrations. The add-on
uses the `mdrap` import namespace and depends on the matching core release.

Core-only installs expose the supported engine API with `import mdrap`. Install
the add-on with `pip install mdrap-contrib` when you need its functionality.
